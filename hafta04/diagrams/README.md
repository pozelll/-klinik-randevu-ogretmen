# 4. haftanın diyagramları

Bu klasör dördüncü basamak için hazırlandı. Henüz bileşen diyagramı çizilmedi.

Dördüncü basamakta diagrams.net ile oluşturulacak dosyalar:
- `01-bilesen.drawio`: Yeniden açılıp düzenlenebilen çizim.
- `01-bilesen.png`: Aynı çizimin görüntüsü.

Randevu oluşturma veya iptal senaryosu için arayüz, iş kuralları ve veri erişimi
sorumluluklarını ve aralarındaki iletişimi gösterin. Okların anlamını belirtin.
Mevcut kod ile önerilen tasarımı ayırt edin; uygulanmamış tasarımı mevcut mimari
olarak sunmayın.

Çizimi önce .drawio olarak kaydedip yeniden açılabildiğini kontrol edin.
PNG'yi aynı sürümden dışa aktarın. Karar gerekçesi
`../docs/02-mimari-karar.md` dosyasında yer alacak.

İlk iki haftanın proje kökündeki diagrams klasörünü değiştirmeyin.
