# 5. hafta / 7. adım - Commit ve PR kaydı

Öğrenci çalışma yönergesi · Güncelleme: 26 Kasım 2026.

## Amaç

Kod değişikliklerini sürüm geçmişine kaydetmek ve inceleme için bağlantılı bir değişiklik paketi hazırlamak.

Commit, bir dosya değişikliği grubunun sürüm kaydıdır. Pull request (PR), bir dalın değişikliklerini hedef dala katma önerisini, dosya farklarını ve inceleme kayıtlarını bir araya getirir. Uygulamayı indirmek için seçilecek dal, değişikliklerin hangi dala birleştirildiğine göre belirlenir.

## Grup çalışması

1. Kendi değişikliklerinizi anlamlı commit'lerle kaydedin.
2. PR oluştururken kaynak dalı (`head`) ve hedef dalı (`base`) belirtin.
3. PR açıklamasına değişikliğin amacını, etkilenen dosyaları ve kendi test sonuçlarınızı ekleyin.
4. İlgili bölümün yazımına katılmamış üyeye inceleme kapsamı verin.
5. Gerçekleşen incelemeyi kişinin adı, incelenen commit, kapsam ve bulgularla kaydedin. Düzeltme gerekiyorsa düzeltme commit'ini ve yeniden kontrol sonucunu ekleyin.
6. Commit, PR ve inceleme bağlantılarını [grup kaydına](../sablonlar/grup-kaydi.md) yazın.
