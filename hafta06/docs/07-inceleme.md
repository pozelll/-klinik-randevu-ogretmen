# 6. hafta / 7. basamak - Kod ve kanıt incelemesi

## Amaç

Gereksinim, kod değişikliği, test beklentisi ve kanıt arasındaki uyumu değerlendirin. İnceleyen kişi, değerlendirdiği içeriğin yazarı veya ortak yazarı olmamalıdır.

## Çalışma

1. Kendi PR'ınızın **Files changed** bölümünde hedef dalı ve değişiklik kapsamını kontrol edin.
2. Başka bir üyeye belirli bir dosya ve kontrol kapsamı verin. Ortak yazılan içerik için gerekirse grup dışından inceleyen belirleyin.
3. Gerçek inceleme sonucunu aşağıdaki kayda işleyin. Otomatik test çalıştırmasını kişi incelemesi olarak kaydetmeyin.
4. Bulgu varsa dosya, etki, düzeltme commit'i ve yeniden kontrol sonucunu birbirine bağlayın.

## İnceleme kayıt formu

| Alan | Grubun kaydı |
|---|---|
| İnceleyen adı / hesabı | |
| İncelenen içeriğin yazımına katılma durumu | |
| İncelenen commit / tarih | |
| Dosya ve test kapsamı | |
| Bulgu / önem / önerilen düzeltme | |
| Düzeltme commit'i / yeniden kontrol | |
| Karar / gerçek GitHub review bağlantısı | |

Yapılmamış bir incelemenin alanlarını onaylanmış gibi doldurmayın; durumunu açıkça belirtin. Bağımlı PR'larda hedef dal değişirse farkı ve kontrol edilen commit'i yeniden doğrulayın.
