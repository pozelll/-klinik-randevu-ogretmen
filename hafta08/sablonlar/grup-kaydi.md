# 8. hafta — Grubun gerçek çalışma kaydı

Bu form boş bırakılmıştır. Öğretmen sonuçlarını kendi yürütümünüz gibi aktarmayın.

## Grubun iş bölümü

[İki, üç ve dört kişilik gruplar için yönlendirmeyi](../../docs/11-grup-buyuklugune-gore-yonlendirme.md) kullanın. Kendi üye sayınızı, her işin yazarlarını, beklenen çıktısını ve yazımına katılmayan inceleyeni kaydedin. İki üyenin de birlikte yazdığı kapsam için başka gruptan veya öğretim elemanından inceleme planlayın; gerçekleşene kadar bekliyor bırakın. Görevleri haftalar arasında değiştirin; aynı kişinin eşzamanlı iki iş yapacağını varsaymayın. Gerçek katkı, kontrol ve inceleme sonucu ancak yapıldıktan sonra doldurulur.

| Alan | Grup tarafından doldurulacak |
|---|---|
| Grup / üyeler / görev sahibi | |
| Başlangıç ve teslim commit'i | |
| Issue / dal / PR | |
| Karar / gerekçe / kapsam dışı işler | |
| Katkı sahibi / dosya / commit | |
| Tahmin ve gerçekleşen emek (ayrı) | |
| Test komutu / tarih / ortam | |
| Beklenen sonuç / gerçek sonuç | |

| İnceleyen / yazarla ilişkisi / commit | |
| Bulgu / düzeltme / yeniden kontrol | |
| Alıcı / erişim ve kabul sonucu | |
| Açık risk / sonraki iş | |
| Ne öğrendik / neyi iyileştireceğiz | |

- [ ] Kendi sürümümüzde kontrolleri çalıştırdık.
- [ ] Gerçek inceleyen ve bulgu kaydını ekledik.
- [ ] Alıcıya erişimi gerçekten doğruladık.
- [ ] Çalıştırılmayan veya onaylanmayan işleri açık bıraktık.
