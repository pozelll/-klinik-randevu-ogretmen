# 8. hafta — Grubun gerçek çalışma kaydı

Bu form boş bırakılmıştır. Öğretmen sonuçlarını kendi yürütümünüz gibi aktarmayın.

| Alan | Grup tarafından doldurulacak |
|---|---|
| Grup / üyeler / görev sahibi | |
| Başlangıç ve teslim commit'i | |
| Issue / dal / PR | |
| Karar / gerekçe / kapsam dışı işler | |
| Katkı sahibi / dosya / commit | |
| Tahmin ve gerçekleşen emek (ayrı) | |
| Test komutu / tarih / ortam | |
| Beklenen sonuç / gerçek sonuç | |
| Paket adı / SHA-256 (H8) | |
| İnceleyen / yazarla ilişkisi / commit | |
| Bulgu / düzeltme / yeniden kontrol | |
| Alıcı / erişim ve kabul sonucu | |
| Açık risk / sonraki iş | |
| Ne öğrendik / neyi iyileştireceğiz | |

- [ ] Kendi sürümümüzde kontrolleri çalıştırdık.

- [ ] Çalıştırılmayan veya onaylanmayan işleri açık bıraktık.
