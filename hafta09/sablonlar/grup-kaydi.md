# H9 - Grubun gerçek çalışma kaydı

Öğretmen sonuçlarını kendi yürütümünüz olarak aktarmayın. Boş alanlar grup tarafından doldurulur.

## Grubun iş bölümü

[İki, üç ve dört kişilik gruplar için yönlendirmeyi](../../docs/11-grup-buyuklugune-gore-yonlendirme.md) kullanın. Kendi üye sayınızı, her işin yazarlarını, beklenen çıktısını ve yazımına katılmayan inceleyeni kaydedin. İki üyenin de birlikte yazdığı kapsam için başka gruptan veya öğretim elemanından inceleme planlayın; gerçekleşene kadar bekliyor bırakın. Görevleri haftalar arasında değiştirin; aynı kişinin eşzamanlı iki iş yapacağını varsaymayın. Gerçek katkı, kontrol ve inceleme sonucu ancak yapıldıktan sonra doldurulur.

| Alan | Gerçek kayıt |
|---|---|
| Grup, üyeler, görev sorumlusu | |
| Başlangıç commit'i ve ürün/sürüm kapsamı | |
| Dal modeli ve seçim gerekçesi | |
| İki feature'ın ortak tabanı ve katkı commit'leri | |
| Çakışan alan, iki ihtiyaç, çözüm gerekçesi | |
| Çözüm commit'i ve kontrol çıktıları | |
| Release dalı, etiket türü/hedefi | |
| Hotfix bulgusu ve başarısız kontrol | |
| Hotfix commit'i, iki hedef, atalık ve içerik sonucu | |
| Komut, ortam, tarih, sonuç dosyası | |
| CI kaynak SHA / koşu bağlantısı | |
| Planlanan ve gerçekleşen emek; birimleri | |
| Yazar dışında inceleyen, incelenen SHA, bulgu | |
| NFR ve performans ölçümü / açık görev | |
| Yayın kararı, karar veren ve gerekçe | |
| Paket SHA-256, alıcı, erişim ve çalıştırma sonucu | |
| 14 konu tablosundaki kendi çıktı bağlantıları | |
| Sonraki proje görevi ve sorumlusu | |

- [ ] Gerçek çakışmayı ve iki katkıyı gösterdik.
- [ ] Eski etiketi taşımadan yeni sürümü kaydettik.
- [ ] Hotfix iki gerekli hedefte hem geçmişte hem son içerikte var.
- [ ] Test sayıları, ölçülmemiş NFR ve insan kabulünü ayırdık.
- [ ] Diğer grup paketi açıp geçmişi ve uygulamayı doğruladı.
